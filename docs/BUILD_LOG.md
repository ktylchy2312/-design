# Build Log

Chronological record of steps taken while building this environment. Append an entry whenever a step is completed — this is a narrative plan/history, not a save point (see [SAVE_POINTS.md](./SAVE_POINTS.md) for those).

## 2026-08-14

1. **Scaffolded the plugin.** Created `.claude-plugin/plugin.json` (name `claude-design`) and `agents/` as the home for subagent definitions.
2. **Created the orchestrator agent** (`agents/orchestrator.md`). Its job: for each task, decide directly vs. delegate vs. parallelize, optimizing for least total tokens and wall-clock time. Holds a registry table of known agents so routing is a lookup, not a re-derivation — currently empty, orchestrator is the only agent.
3. **Wrote `CLAUDE.md`.** Curated 4 principles from `assets/andrej-karpathy-skills-main` (Simplicity first, Surgical changes, State assumptions don't guess, Goal-driven), adapted to this project rather than copied verbatim. Rest of the structure follows Anthropic's documented CLAUDE.md conventions (headers/bullets, <200 lines, concrete/verifiable rules).
4. **Moved `andrej-karpathy-skills-main` into `assets/`.** It's vendored reference material, not part of the plugin — kept separate so it's clear it's not something this project edits or ships.
5. **Ran `git init`.** No commit yet — orchestrator and CLAUDE.md are still being iterated on. First commit will double as the first save point (see SAVE_POINTS.md).
6. **Widened orchestrator's scope.** It now coordinates three kinds of capability, not just agents: subagents, skills, and other installed plugins. Split its single registry table into three (Agents / Skills / Plugins) and added "invoke a skill" as a cheaper middle option between doing work directly and delegating to a subagent. `CLAUDE.md` updated to match.
7. **Added Anthropic's skill design principles to the orchestrator.** New "Skill principles" section: progressive disclosure (registry holds one-line descriptions only — full instructions and reference files load in later levels, only on actual use), composability (skills combine with agents/direct action, never treated as exclusive), portability (skills assumed surface-agnostic; a missing dependency is an environment gap, not grounds to avoid the skill).
8. **Added a code-writing section to `CLAUDE.md`.** Governs any code/script/bash this environment produces: senior full-stack engineer persona, simple over clever, break work into small verified steps instead of one large change, token economy as the governing constraint, no speculative code.
9. **Built the live Figma bridge, Phase 1 (read).** New `figma-plugin/` — a Figma Plugin API plugin (`code.js`/`ui.html`/`manifest.json`) plus a local relay (`bridge/server.mjs`) and one-shot CLI (`bridge/cli.mjs`) so Claude Code can drive it over Bash. Chosen over browser automation (user's call) and over an MCP-wrapped relay (unverified plugin-MCP auto-start behavior — CLI-shellout was the simpler, already-understood path). Reads live selection/page/node-tree — the thing the separately-installed `figma-bridge` plugin's static REST reads structurally can't see. Node.js wasn't installed on this machine; installed it (winget, user's choice) before `npm install`. Verified live: relay + plugin connect, `get_status`/`get_selection` return real data from the open document.
10. **Built Phase 2 (generic write) and the `figma-live-bridge` agent.** Re-scoped from the original plan's per-shape ops to one generic primitive: `create_node` (type: RECTANGLE/ELLIPSE/LINE/TEXT/FRAME), `set_node_property` (allowlisted props, handles async font-loading for text), `move_node`. Deliberately not building per-type or higher-level "how to build a button" ops here — that's pushed to a planned `design-system` skill/agent (Phase 3, not yet built) so `code.js` stays small. Added `agents/figma-live-bridge.md` and its row in `agents/orchestrator.md`'s Agents table.
11. **Verified Phase 2 live and fixed a real quoting bug.** Created a rectangle, a text node (content set via the async font-load path), and an auto-layout frame, then reparented the rectangle into it — geometry snapped to the frame's padding as expected, confirming auto-layout genuinely engaged. Along the way: PowerShell 5.1 silently mangles double-quoted JSON args containing spaces before they reach `node.exe` (confirmed via `process.argv` — quotes vanish, string splits on spaces). Fixed by adding an `@path/to/file.json` form to `cli.mjs` that reads params from a file instead of argv, sidestepping shell quoting entirely.
